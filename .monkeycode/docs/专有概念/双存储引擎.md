# 双存储引擎

双存储引擎是 StoneVault 的核心存储模型，通过"SSD 热区 + HDD 冷区"分层实现功耗与性能的平衡。

## 什么是双存储引擎？

系统将存储划分为热区（固态存储，eMMC/SSD）与冷区（机械硬盘 HDD）两层。热区存放数据库、全文索引、缩略图与近期压缩缓存副本，保证查询与预览的低延迟；冷区存放所有原始文件的完整副本，空闲时休眠以降低功耗。

**关键特征**:
- 备份写入时先写冷区完整副本，再写热区压缩缓存与索引
- 查询/预览只读热区与数据库，不唤醒冷区
- 下载/恢复源文件时按需唤醒冷区并流式传输

## 不变量

1. **写入顺序**: 冷区完整副本写入并校验成功后，才写入热区缓存与索引。
2. **查询隔离**: 查询与预览操作不触发冷区访问。
3. **唤醒防抖**: 同一时间窗口内多个冷区请求共享同一次唤醒。
