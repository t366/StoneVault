# 备份任务

备份任务是 StoneVault 执行自动备份的配置单元，将源目录的文件按规则复制到冷区并建立索引。

## 什么是备份任务？

一项备份任务包含源目录、冷区目标相对路径、文件过滤规则（后缀/大小）与调度规则（Cron）。每次执行生成一条快照记录，并对每个文件建立 `file_index` 索引，记录热区缓存路径与冷区源路径。

**关键特征**:
- 支持全量与增量两种备份模式
- 增量模式基于 mtime 与 MD5 比较，仅传输变更文件
- 支持文件过滤（扩展名黑白名单、大小上下限）
